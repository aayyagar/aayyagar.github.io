Quantum-Ready Windows PKI

Finds the cryptography in a Windows and Active Directory estate that a quantum computer could break, and ranks it by how long the data it protects must stay secret.

  • Where Windows keeps its keys: AD CS CAs and templates, TLS on LDAPS, RDP, IIS and WSUS, Kerberos encryption types and PKINIT.
  • Ranked by Mosca's inequality: shelf life plus migration time against the quantum year, so 25-year HR data comes before a 2-year intranet.
  • Windows-specific paths: ML-DSA CAs on Server 2025, hybrid ML-KEM in Schannel, CNG templates, and Kerberos RC4 removal (CVE-2026-20833).
  • Outputs: HTML report, five-phase roadmap and a CycloneDX 1.6 cryptography bill of materials.

Policy Replay

A GitHub Action for Conditional Access kept in Git: it replays the last 30 days of real sign-ins against the policies before and after a pull request, and comments who would be blocked, prompted or let through.

  • Real traffic, not hypotheticals: a local Conditional Access engine evaluates users, groups, roles, apps, platforms, locations, risk and grant controls for every recent sign-in.
  • Protects break-glass: fails the check when an emergency access account would be locked out, and highlights admins and guests.
  • Catches quiet loosening: flags new exclusions whose effect another change in the same pull request hides.
  • Secret-free: signs in with a GitHub OIDC federated credential, reads only, and can redact user names in comments.
