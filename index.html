CIS Benchmark Hardening Suite

A single-file PowerShell tool that hardens Windows and Linux servers to CIS benchmarks, then produces an HTML compliance report. No installs and no extra files.

  • Two ways to run it: a browser-based control picker served from a local listener, or a terminal wizard that lets you approve each control.
  • Framework isolation: choosing CIS, NIST SP 800-53, PCI-DSS v4.0, HIPAA or SOX locks out the others' controls, so audit scopes never mix.
  • Levels up to Zero Trust and NSA/CNSS: L4 maps to STIG, L5 to Zero Trust, L6 to NSA/CNSS, across 7 control categories.
  • Wide coverage: Server 2016–2025, Windows 10/11, and RHEL, Ubuntu, Debian, SUSE, Fedora, Amazon Linux and more.

Enterprise Active Directory Security Architecture

A complete playbook for designing, securing and running Active Directory in a hybrid enterprise, written for domain architects, AD admins and security engineers.

  • Privileged access: Tier 0–3 model, jump servers, PAWs, PIM, service-account lifecycle and passwordless sign-in.
  • Hybrid identity: Entra ID hardening, Entra Connect health, ADFS federation and Zero Trust with AD.
  • Attack surface: ADCS ESC1–ESC8, Kerberos attacks, and red-team attack path analysis.
  • Detection & recovery: a KQL and SPL query library for SIEM, DC disaster recovery and break-glass procedures.
  • Ready to use: GPO baselines, a full AD port and firewall reference, health-check scripts and an RFC change template.
